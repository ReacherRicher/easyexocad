# EasyExoCad

آموزش حرفه‌ای اگزو کد دندانپزشکی

## Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS** + `tailwindcss-rtl`
- **Vazirmatn** (Google Fonts) — Persian font
- **gray-matter** — MDX frontmatter
- **next-mdx-remote** — MDX rendering
- **next-sitemap** — sitemap generation

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Folder Structure

```
src/
  app/             # Next.js App Router pages
  components/
    layout/        # Navbar, Footer
    ui/            # Reusable UI components
  lib/             # Utility helpers
  content/
    courses/       # Course JSON data files
    blog/          # MDX blog posts
public/
  images/          # Image assets
```
